Train your AI on it

Game worlds are a popular way to test driving and navigation AI. This one uses real streets and no game files: your agent reads road sensors, sends steering and throttle, and gets a reward. It's built for prototypes and demos, not real vehicles.

Add it in a minute

No API key, no build step. Paste this into any page.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/maplibre-gl@5.6.0/dist/maplibre-gl.css">
<link rel="stylesheet" href="https://wesomitsu.github.io/gta6-map/src/neonmap.css">
<div id="map" style="height:500px"></div>

<script src="https://cdn.jsdelivr.net/npm/maplibre-gl@5.6.0/dist/maplibre-gl.js"></script>
<script src="https://wesomitsu.github.io/gta6-map/src/neonmap.js"></script>
<script>
  NeonMap.create('#map', {
    theme: 'sunset',
    places: [
      { name: 'Ocean Loft', lng: -80.1300, lat: 25.7850, price: '$189', url: '/stays/ocean-loft' },
      { name: 'Palm Suites', lng: -80.1340, lat: 25.7920, price: '$142', url: '/stays/palm-suites' }
    ]
  });
</script>
